# Darshil Shah — Portfolio Website

A modern, animation-rich portfolio built with Next.js, Framer Motion, GSAP, and Lenis smooth scrolling.

## Tech Stack

- **Next.js 16** (App Router)
- **React 19** + TypeScript
- **Tailwind CSS v4**
- **Framer Motion** — UI animations & magnetic buttons
- **GSAP + ScrollTrigger** — scroll reveals & timeline
- **Lenis** — smooth scrolling

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Push this project to a GitHub repository
2. Import the repo at [vercel.com/new](https://vercel.com/new)
3. Vercel auto-detects Next.js — click Deploy

Or use the CLI:

```bash
npx vercel
```

## Project Structure

- `app/` — Next.js pages, layout, global styles
- `components/` — UI, layout, and section components
- `content/site.ts` — All portfolio content (edit here to update copy)
- `public/assets/` — Images, GIFs, and resume PDF

## Content Updates

Edit `content/site.ts` to update skills, experience, projects, and social links.
